# MiniSwerveLib Manual

## Overview

`MiniSwerveLib` is the swerve drive library for the MiniFRC 2026 robot codebase. It provides three primary classes:

- `SwerveDrive` - robot-level swerve subsystem management
- `SwerveModule` - one wheel module with drive motor, steering servo, and steering encoder
- `QuicEncoder` - quadrature encoder reader with interrupt-driven updates

The current implementation is designed around an external Adafruit seesaw breakout board for encoder input. The library reads the encoder A/B channels directly from the seesaw GPIO pins while keeping the same transition-table based quadrature decode logic.

## Hardware Model

The library assumes the following hardware layout:

- Drive motors are connected to NoU motor controller ports.
- Steering servos are connected to NoU servo ports.
- Steering encoders are wired to a seesaw breakout board.
- The seesaw interrupt output is wired to ESP GPIO 9.

The encoder channel mapping is fixed in the library:

- Encoder 0: A=8, B=9
- Encoder 1: A=10, B=11
- Encoder 2: A=2, B=3
- Encoder 3: A=4, B=5

## Class Relationships

- `SwerveDrive` owns four `SwerveModule` objects.
- Each `SwerveModule` owns one `QuicEncoder`.
- `QuicEncoder` is configured globally to use the seesaw object and seesaw interrupt line before the module encoders are created.
- When a seesaw interrupt occurs, the shared ISR dispatches updates to all tracked encoders.

## SwerveDrive

`SwerveDrive` is the top-level subsystem class. It stores the four modules, robot-level speed settings, and IMU scaling.

### Constructor

```cpp
SwerveDrive(
    uint8_t driveMotorPorts[4],
    std::array<bool, 4> driveMotorInversions,
    std::array<float, 4> driveGearRatios,
    uint8_t turnServoPorts[4],
    std::array<float, 4> turnServoOffsets,
    std::array<bool, 4> turnServoInversions,
    std::array<float, 4> turnServoGearRatios,
    std::array<uint16_t, 2> servoConfig,
    std::array<bool, 4> turnEncoderInversions,
    Adafruit_seesaw *encoderSeesaw,
    float imuAngularScale,
    float maxSpeed
)
```

### Parameters

- `driveMotorPorts` Port numbers for the four drive motors in module order `{FL, FR, BL, BR}`.
- `driveMotorInversions` Drive motor inversion flags, one per module.
- `driveGearRatios` Drive gear ratios, one per module.
- `turnServoPorts` Servo ports for the four steering motors in module order `{FL, FR, BL, BR}`.
- `turnServoOffsets` Steering zero offsets in degrees.
- `turnServoInversions` Steering inversion flags, one per module.
- `turnServoGearRatios` Steering gear ratios, one per module.
- `servoConfig` Servo PWM limits as `{minPulse, maxPulse}`.
- `turnEncoderInversions` Encoder inversion flags for each module.
- `encoderSeesaw` Initialized seesaw object used to read encoder GPIO pins.
- `imuAngularScale` Scale factor used for IMU angular readings.
- `maxSpeed` Global maximum commanded linear speed.

### Behavior

Construction automatically configures the seesaw encoder system and assumes the interrupt line is connected to ESP GPIO 9.

### Public Methods

#### `getTargetVelocities`

```cpp
std::vector<float> getTargetVelocities(float xJoystick, float yJoystick, float rotationJoystick, float scale, bool robotOriented);
```

### Parameters

- `xJoystick` Forward/backward joystick input.
- `yJoystick` Left/right joystick input.
- `rotationJoystick` Rotation input. Positive values mean counterclockwise.
- `scale` Velocity scaling multiplier.
- `robotOriented` When true, the command is interpreted in robot-oriented coordinates.

### Returns

- A vector containing `{x, y, angular}` velocity components.

### Notes

This method is declared in the API but is not yet implemented in the current source.

#### `drive`

```cpp
void drive(std::vector<float> velocities, float driveSpeed);
```

### Parameters

- `velocities` Velocity vector generated by `getTargetVelocities()`.
- `driveSpeed` Scalar drive speed target.

### Behavior

Applies the same steering angle and drive speed to all four modules using `driveModule()`.

#### `setModuleStates`

```cpp
void setModuleStates(float targetAngles[4], float driveSpeeds[4]);
```

### Parameters

- `targetAngles` Per-module steering angles in degrees.
- `driveSpeeds` Per-module speed targets.

### Behavior

Forwards the explicit angle and speed values to each module using `directDriveModule()`.

#### `driveToPoint`

```cpp
void driveToPoint(float x, float y, float targetAngle, float maxSpeed);
```

### Parameters

- `x` Target X position.
- `y` Target Y position.
- `targetAngle` Desired robot heading.
- `maxSpeed` Speed cap for the maneuver.

### Notes

Declared for future path/point driving support. It is currently a placeholder.

#### `setBrakeMode`

```cpp
void setBrakeMode(bool brake);
```

### Parameters

- `brake` When true, enable braking on each drive motor. When false, coast.

### Behavior

Applies the requested brake mode to all four modules.

#### `setMaxSpeed`

```cpp
void setMaxSpeed(float maxSpeed);
```

### Parameters

- `maxSpeed` New maximum linear speed.

### Behavior

Stores the new global maximum speed value.

#### `setIMUScale`

```cpp
void setIMUScale(float imuAngularScale);
```

### Parameters

- `imuAngularScale` New IMU scale factor.

### Behavior

Stores the new IMU angular scale.

#### `getOdeometry`

```cpp
std::array<float, 3> getOdeometry();
```

### Returns

- An array containing `{x, y, heading}`.

### Notes

Currently returns zeroed values because odometry is not yet implemented.

#### `resetOdeometry`

```cpp
void resetOdeometry(float x, float y, float angle);
```

### Parameters

- `x` New X position.
- `y` New Y position.
- `angle` New heading in degrees.

### Notes

Declared for future odometry support. The current implementation is a placeholder.

#### `swerveDrivePeriodic`

```cpp
void swerveDrivePeriodic();
```

### Behavior

Calls `updateModuleState()` on each module so encoder state stays current.

#### `getModule`

```cpp
SwerveModule *getModule(int index);
```

### Parameters

- `index` Module index in the range `[0, 3]`.

### Returns

- Pointer to the requested module, or `nullptr` if the index is invalid.

#### `getDrive`

```cpp
SwerveDrive getDrive();
```

### Returns

- A copy of the current drive object.

## SwerveModule

`SwerveModule` manages one swerve corner, including the drive motor, steering servo, and steering encoder.

### Constructor

```cpp
SwerveModule(
    uint8_t driveServoPort,
    bool driveMotorInversion,
    uint8_t turnServoPort,
    bool turnServoInversion,
    float angleoffset,
    float drivegearratio,
    float turngearratio,
    float encoderGearRatio,
    std::array<uint16_t, 2> servoConfig,
    std::array<uint8_t, 2> turnEncoderPins,
    bool turnEncoderInversion,
    bool brakeMode
)
```

### Parameters

- `driveServoPort` Port for the drive motor controller.
- `driveMotorInversion` Drive motor inversion flag.
- `turnServoPort` Port for the steering servo.
- `turnServoInversion` Steering inversion flag.
- `angleoffset` Steering zero offset in degrees.
- `drivegearratio` Drive gearing ratio from motor to wheel.
- `turngearratio` Steering gearing ratio from servo to module.
- `encoderGearRatio` Encoder gearing ratio used when converting position feedback.
- `servoConfig` Servo PWM bounds as `{minPulse, maxPulse}`.
- `turnEncoderPins` Seesaw GPIO pair `{pinA, pinB}` used by the encoder.
- `turnEncoderInversion` Encoder direction inversion flag.
- `brakeMode` Initial brake mode for the drive motor.

### Behavior

- Creates a NoU motor for drive output.
- Creates a NoU servo for steering.
- Creates a `QuicEncoder` for the steering feedback.
- Sets motor inversion and brake mode.
- Initializes the drive encoder and the steering encoder.

### Public Methods

#### `driveModule`

```cpp
void driveModule(float targetAngle, float driveSpeed);
```

### Parameters

- `targetAngle` Desired module steering angle.
- `driveSpeed` Desired drive speed.

### Behavior

Runs the module drive command using the module's steering offset and current control logic.

#### `directDriveModule`

```cpp
void directDriveModule(float targetAngle, float driveVelocity);
```

### Parameters

- `targetAngle` Desired steering angle.
- `driveVelocity` Desired directional drive velocity.

### Behavior

Directly writes the steering servo and drive motor without optimization.

#### `getModuleAngle`

```cpp
float getModuleAngle();
```

### Returns

- The current module angle in degrees.

#### `getModuleVelocity`

```cpp
float getModuleVelocity();
```

### Returns

- The current wheel speed estimate.

#### `setBrakeMode`

```cpp
void setBrakeMode(bool brake);
```

### Parameters

- `brake` When true, enable braking. When false, coast.

#### `updateModuleState`

```cpp
void updateModuleState();
```

### Behavior

Updates the encoder, refreshes the stored steering angle, and keeps the module state current.

#### `getDriveMotor`

```cpp
NoU_Motor *getDriveMotor();
```

### Returns

- Pointer to the internal drive motor.

#### `getTurnServo`

```cpp
NoU_Servo *getTurnServo();
```

### Returns

- Pointer to the internal steering servo.

#### `getTurnEncoder`

```cpp
QuicEncoder *getTurnEncoder();
```

### Returns

- Pointer to the internal steering encoder.

#### `getModule`

```cpp
SwerveModule getModule();
```

### Returns

- A copy of the module object.

## QuicEncoder

`QuicEncoder` reads quadrature encoder signals and maintains a signed position count.

### Static Configuration

#### `configureSeesaw`

```cpp
static void configureSeesaw(Adafruit_seesaw *seesaw);
```

### Parameters

- `seesaw` Pointer to the initialized seesaw object used for GPIO reads.

### Behavior

Sets the shared seesaw instance used by all `QuicEncoder` objects.

#### `configureSeesawInterruptPin`

```cpp
static void configureSeesawInterruptPin(int8_t interruptPin);
```

### Parameters

- `interruptPin` MCU pin connected to the seesaw INT line.

### Behavior

Stores the interrupt pin used to attach the shared ISR dispatch when seesaw-backed reads are active.

### Constructor

```cpp
QuicEncoder(uint8_t pinA, uint8_t pinB, bool inverted = false);
```

### Parameters

- `pinA` Encoder channel A. In seesaw mode this is the seesaw GPIO pin number.
- `pinB` Encoder channel B. In seesaw mode this is the seesaw GPIO pin number.
- `inverted` Encoder direction inversion flag.

### Behavior

- Stores the encoder pin pair.
- Reads the initial pin state.
- Registers the encoder for shared interrupt-driven updates.
- Uses direct MCU pins when no seesaw is configured.

### Public Methods

#### `initialize`

```cpp
void initialize();
```

### Behavior

Present for compatibility with the rest of the library. The encoder is already set up by the constructor and global seesaw configuration.

#### `getPosition`

```cpp
int32_t getPosition();
```

### Returns

- The current encoder position.

#### `resetPosition`

```cpp
void resetPosition(int32_t newPosition = 0);
```

### Parameters

- `newPosition` New position value to store.

### Behavior

Resets the internal position counter atomically.

#### `update`

```cpp
void update();
```

### Behavior

Reads the current A/B signal state, applies the quadrature transition table, and updates the signed position count.

That example shows:

- relying on the fixed encoder mapping
- relying on the ESP GPIO 9 interrupt assumption

## Example Wiring Summary

- Swerve encoder 0: seesaw GPIO 8 and 9
- Swerve encoder 1: seesaw GPIO 10 and 11
- Swerve encoder 2: seesaw GPIO 2 and 3
- Swerve encoder 3: seesaw GPIO 4 and 5
- seesaw INT: ESP GPIO 9

## Limitations and Notes

- `getTargetVelocities()` is declared but not yet implemented.
- `driveToPoint()` is declared but not yet implemented.
- Odometry methods are placeholders for now.
- The documentation reflects the current seesaw-backed encoder behavior rather than direct MCU pin encoder wiring.

## Suggested Integration Order

1. Create and initialize the seesaw object.
2. Construct `SwerveDrive` and pass the seesaw pointer.
3. Call `swerveDrivePeriodic()` during the robot loop.
4. Read module state through the `SwerveModule` accessors if needed.
